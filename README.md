# StudyFlow — Student Task Planner

A beginner-friendly task planner made with **HTML, CSS and vanilla JavaScript**.

## Features
- Add tasks and choose Low, Medium or High priority
- Mark tasks as completed
- Filter All / To do / Completed
- Delete tasks
- See total, remaining and completed task counts
- Saves tasks in the browser with `localStorage`
- Responsive layout for mobile and desktop

## Run it
Open `index.html` in any modern web browser. No installation or server is required.

## Technologies
- HTML5
- CSS3
- JavaScript (DOM, events and localStorage)

## Note
Tasks are stored locally in the browser being used. They are not synced between devices.
